# App icon source

The whale mark in `app-icon.svg` is copied without path or color changes from
DeepSeek's official `ICON.svg` brand asset:

- Source: <https://github.com/deepseek-ai/awesome-deepseek-integration/blob/main/docs/_logo%20svg/ICON.svg>
- Raw source: <https://raw.githubusercontent.com/deepseek-ai/awesome-deepseek-integration/main/docs/_logo%20svg/ICON.svg>
- Downloaded SHA-256: `b15083e3cbb398bd35619b758c43adc0a632efccc7e2d69f2481a860862910fe`
- Brand color: `#4d6bfe`
- Usage guidelines: <https://github.com/deepseek-ai/awesome-deepseek-integration/blob/main/docs/_logo%20svg/guidelines.md>

`deepseek-icon-official.svg` is the exact upstream file downloaded on
2026-08-04. `app-icon.svg` places that unchanged mark on a light neutral square
tile for this project's internal macOS build. Generated PNG, ICNS, ICO, and
Windows Store assets are derived from `app-icon.svg`.

DeepSeek's guidelines require an actual DeepSeek model/API integration and
prohibit false partnership claims or impersonation of official DeepSeek
channels. Public distribution should receive a separate trademark review.
